# BrewBridge-Cafe-Analysis
# ☕ BrewBridge Café – Business & Loyalty Campaign Analysis (Q2 2025)

## 📌 Project Overview
This project analyzes sales, customer behavior, and the effectiveness of a year‑end loyalty campaign for **BrewBridge Café**, a specialty coffee brand in India. The analysis is based on real (anonymized) data from Q2 2025 (April–June).

**Key business questions answered:**
- Customer segmentation (region, city, membership tier, age)
- Most popular menu items & revenue breakdown
- Impact of loyalty campaign (did recipients spend more?)
- Which reward type performed best?
- Correlation analysis & outlier detection (catering opportunities)

## 📊 Tools & Libraries
- Python 3.10+
- Pandas, NumPy – data cleaning & aggregation
- Matplotlib, Seaborn – visualizations
- Jupyter Notebook

## 📁 Files
- `BrewBridge_Analysis.ipynb` – complete Python analysis with comments
- `images/` – all charts (boxplots, heatmaps, bar charts)
- `BrewBridge_Report.pdf` – professional business report

## 🔍 Key Findings
- **100% customer engagement** – all 200 customers ordered in Q2.
- **Loyalty campaign recipients spent 74% more** than non‑recipients.
- **Best reward:** “10% Off Next Visit” (highest total spend & redemptions).
- **Highest basket size:** “Double Loyalty Points” (₹725/order).
- **Customer ratings are NOT correlated** with price or discount – satisfaction depends on service quality.
- **Bulk orders** (₹9,240, 32 pasta salads) suggest demand for catering.
